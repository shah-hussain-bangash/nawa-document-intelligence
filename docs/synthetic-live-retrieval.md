# Synthetic live retrieval experiment

The offline BM25 index is a snapshot. An index constructed before an access or source change can continue returning an old passage. `SyntheticLiveRetrieval` experiments with rebuilding from callback-provided eligible passages and rechecking the principal and filtered snapshot before returning search results. Resolving a passage ID takes a fresh snapshot and rechecks it again. Synthetic tests cover two tenants with positive controls, a replaced version, withdrawal, identity changes and dependency errors.

The first callback tests use in-memory fixtures. The loader must itself establish the current approved source and exclude withdrawn or obsolete versions. The experiment has no endpoint, authorization of exports, independent evaluation or production identity provider. Re-reading snapshots does not prevent a change after the final check or a change that occurs and reverts between checks. This is not an authorization boundary or a production release gate. Do not use it to justify returning real or confidential data.

An additional disposable PostgreSQL experiment supplies the callbacks from local membership, tenant and version records. It admits only the latest explicitly versioned, completed, promoted and approved TXT source, validates the review ledger and checks retained bytes against the stored digest. It fails closed if a newer version exists without approval or a retained source is altered. A new synthetic-only migration adds one-way withdrawals: a current reviewer can record a reason and hashed actor, and the retrieval experiment excludes the withdrawn version without reviving an older version. It does not change other application paths or delete source data. A database administrator can alter records; the experiment is not a tamper-proof audit or a production migration. There is no per-document ACL or authenticated HTTP access. It does not prove that extracted values or reviewer corrections are semantically correct. PostgreSQL and file reads are not atomic, and the general two-read race limitations still apply. The test uses disposable synthetic records only.
