# Synthetic scanned quotation evaluation

This baseline measures the default-branch Python PDF demo with six one-page image-only PDFs, generated by the linked evaluation script. It uses English labels, Arabic labels, or a bilingual mix, with one valid quotation and one deliberately incorrect VAT amount per layout. All samples use AED and the same simple layout structure. The four rejected files count as zero returned fields and zero usable evidence references.

| Synthetic input | Exact fields | OCR page references | Correct VAT outcomes | Time per file |
| --- | ---: | ---: | ---: | --- |
| English labels (2 files) | 12/12 | 12/12 | 2/2 | 0.26 s each |
| Arabic labels (2 files) | 0/12 | 0/12 | 0/2 reached | 0.29–0.32 s |
| Mixed labels (2 files) | 0/12 | 0/12 | 0/2 reached | 0.31 s each |

Both English files returned all six fields. The valid file passed the VAT check, and the incorrect VAT was detected in the other file. Both Arabic files were rejected because required VAT fields were missing. Both mixed files were rejected because required subtotal, VAT, and total fields were missing. Rejected files require manual review. Page-reference counts verify that each returned field points to OCR text on page 1. A single-page fixture gives no evidence for multi-page citation accuracy or bounding-box accuracy.

## Reproduce

Use Python 3.12, PyMuPDF 1.26.6, Pillow 13.0.0 with RAQM enabled, Tesseract 5.5.0 with `eng` and `ara` language data, and DejaVu Sans. Timings are wall-clock observations from one local run. Different OCR models, fonts, or machines can change the results.

```bash
python -m pip install -r demo/requirements-pdf.txt Pillow==13.0.0
tesseract --list-langs
cd demo
PYTHONPATH=. python ../scripts/evaluate_scanned_quotations.py /path/to/DejaVuSans.ttf
python -m unittest discover -s tests -q
```
