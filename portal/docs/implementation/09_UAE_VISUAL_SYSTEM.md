# UAE AI visual system

Identity: independent UAE-focused enterprise intelligence workspace. The original
falcon-inspired geometric mark suggests focus and connected evidence. The muted
red edge, emerald field and warm ivory/gold accents acknowledge regional visual
language without reproducing a government seal. SVG assets remain sharp at any size.

Primary emerald #103d35 / #126650; gold #d9b66f; page ivory #f4f6f4;
primary text #193b34; secondary text #5d706c; border #dfe7e3.
Gold is an accent, not the body text colour on white backgrounds.

Navigation uses a dark fixed sidebar on desktop and an accessible menu on mobile.
The overview prioritises current work: context, task shortcuts, metric links,
procurement table, reviews, activity and analytics. Reports expose the evidence
and review record rather than presenting a recommendation as an executed award.

Minimum regular body copy 13–15px; section headings 16px; page headings 25–30px.
Smaller type is reserved for metadata. Focus outlines, semantic labels, modal
focus trapping and reduced-motion support are preserved. Responsive breakpoints
must be checked at 390px, 768px, 1024px and 1440px in LTR/RTL. Table overflow stays
within panels; mobile procurement rows become cards.

Files: src/uae-theme.css, src/styles.css, src/ui.tsx, public/favicon.svg and
public/emirates-skyline.svg. System fonts avoid an external font/CDN dependency.
